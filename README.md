# Netflix Movies & TV Shows Data Analysis Using pandas

## Project Overview

This project analyzes the Netflix Movies & TV Shows dataset using Python and Pandas. The objective is to discover trends in Netflix content such as movie vs TV show distribution, top producing countries, content ratings, release years, genres, and more through data cleaning, analysis, and visualization.

## Dataset

- Source: Kaggle
- Dataset: Netflix Movies and TV Shows
- Records: 8,807
- Features: 12 columns
